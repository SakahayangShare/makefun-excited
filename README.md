A tiny program that presents one exciting image: a young dragon made of shimmering aurora light racing a glowing comet across a starry night sky above mountain peaks, its rider laughing with arms spread wide — pure speed and wonder, made to get the AI judge excited. The program copies the bundled image to /output/entry.png, byte for byte, on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
